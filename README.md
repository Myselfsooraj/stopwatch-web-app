⏱️ Modern Interactive Stopwatch

A sleek and responsive stopwatch application built with HTML, CSS, and JavaScript. The project features millisecond precision timing, lap recording, dark/light mode switching, local storage support, and a modern glassmorphism-inspired user interface.

🚀 Features

* ▶️ Start Stopwatch
* ⏸️ Pause Stopwatch
* 🔄 Reset Stopwatch
* 🏁 Record Unlimited Lap Times
* 🌙 Dark Mode / ☀️ Light Mode Toggle
* 💾 Theme Preference Saved Using Local Storage
* 📱 Fully Responsive Design
* ⚡ Real-Time Millisecond Precision
* 🎨 Modern Glassmorphism UI
* ✨ Smooth Animations & Hover Effects

🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Local Storage API
* CSS Flexbox
* CSS Media Queries
* DOM Manipulation

🎯 How It Works

Start

Begins the stopwatch and starts tracking time.

Pause

Temporarily stops the timer while preserving the elapsed time.

Reset

Resets the stopwatch back to 00:00:00:000 and clears all recorded laps.

Lap

Captures and stores the current elapsed time without stopping the stopwatch.

Theme Toggle

Switch between Dark Mode and Light Mode. The selected theme is automatically saved and restored when the page is reopened.
